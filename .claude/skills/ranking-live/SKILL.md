# ランキング実況(個人ランキング → X)

`@princess_tower8`から、ランク戦 個人ランキングの動きを「実況」として投稿する。

**実況が普通のランキング投稿と違うのは、前回からの変化を語れる点にある。** 「1位はMikuです」は
ただのデータだが、「Mikuが3日連続で首位」「ついに首位交代」「2位が5ポイントまで詰めた」は
ニュースになる。だから毎回スナップショットを残し、次回はそれとの差分から切り口を選ぶ。

投稿の作法(URL・ハッシュタグ・非公式表記・ブラウザ操作の癖)は`x-post`スキルと共通なので、
**投稿の段になったら`x-post`のSKILL.mdを読んでその手順に従う**。ここではデータの取り方と
切り口の選び方だけを扱う。

## 手順

### 1. データを取る

```
python .claude/skills/ranking-live/scripts/collect.py
```

グローバル上位10人を取得し、`history/players.tsv`に追記したうえでJSONを表示する。
追記するのは次回の差分のためなので、**下見だけで投稿しないと決めている場合は`--no-record`**を
付ける(記録が増えると「連続首位日数」が実態とずれる)。

- `--limit N` … 人数(既定10)
- `--country XX` … 国別。**国別は記録しない**(グローバルと混ぜると連続首位日数が狂うため)

出力のうち実況に効くのは次の項目。

| 項目 | 意味 |
|---|---|
| `diff.leader_changed` | 首位が入れ替わったか。**真なら最優先の切り口** |
| `leader_streak_days` | 同じ人が何日連続で首位か(暦日で数える) |
| `gap_1_2` | 1位と2位のレーティング差 |
| `spread_1_last` | 1位と最下位(既定10位)の幅 |
| `diff.entered` / `diff.left` | トップ10に入った人・落ちた人 |
| `diff.climbers` / `diff.fallers` | 順位を上げた人・下げた人(上位3件) |
| `diff.first_run` | 記録が無く比較できない(初回) |

### 2. 切り口を選ぶ

**上から順に見て、最初に当てはまったものを主役にする。** 上にあるものほどニュース性が高い。
同じ切り口が続くと飽きられるので、ネタが並んだときは前回と違う方を選ぶ
(`history/` の件数と`X運用記録.md`で前回何を出したか分かる)。

1. **首位交代**(`leader_changed`) — 最も強い。誰から誰へ、何ポイント差で抜いたかを書く
2. **トップ10の出入り**(`entered`/`left`が空でない) — 新顔の登場、常連の陥落
3. **連続首位**(`leader_streak_days >= 2`) — 「n日連続で首位」。王者が固まってきた話
4. **大接戦**(`gap_1_2`が小さい) — 1位と2位の差、トップ10の幅の詰まり具合
5. **大きな順位変動**(`climbers`/`fallers`の`rank_change`が大きい) — 誰が何位上げたか

初回(`first_run`)や動きが無い日は4番が使える。**4番は履歴を持たなくても今のデータだけで
書けるので、実況が成立しない日の安全弁になる。**

**ユーザーが好むのは「XXとXXがデッドヒート!」「XXが急上昇!」のような、人を主役にした見出し**
(2026-09-28に指示。同じ日に出したデッキ・カード・名前の集計ネタは全部却下された)。
切り口を選んだら、見出しをこの形にする。

- **前回の記録が何日も前なら、1〜3番は「実況」にならない。** 9/28は6日ぶりの実行で、上位10人中
  9人が入れ替わっていた。そういう日は下の「急上昇」か4番(デッドヒート)を選ぶ
- **デッドヒートは、当人たちが今対戦しているかを対戦履歴で確かめる。** 9/28は世界1位と2位が16点差
  だったが、2人とも数時間対戦しておらず見送った。ただし差が極端に小さければ(同日の日本1位・2位は
  1点差)、「競り合っている最中」とは書かずに「先に動くのは?」とにらみ合いとして出してよい
- **日本ランキングも候補にする**(`collect.py --country JP --no-record`、または
  `/ranking/players/table?country=JP`)。本文が日本語なので日本のプレイヤーが主役だと刺さりやすく、
  9/28に日本の1位争い・日本のプレイヤーの急上昇を出した。見出しと順位は「日本ランキング」「日本1位」と書き、
  リンクは`/ranking/players?country=JP&from=x`にする

#### 急上昇(上位1000人の数時間の動き)

`collect.py`は上位10人しか見ないので、上位1000人の中の急上昇はこの方法で探す。

1. トッププレイヤーのデッキ画面(`/decks?page=1`〜`10`)の順位・レーティングは、**集計を始めた
   時点**のもの。時刻はサーバーログの`top deck collector: started collecting`で分かる
   (`sudo journalctl -u clash-royale-api | grep 'top deck collector'`。9/28は08:40 UTC=日本時間17:40。
   画面の「集計日時」は終わった時刻で、約1時間後)
2. 今の`/ranking/players/table`と、タグで突き合わせてレーティングの伸びが大きい人を出す
3. 本人のプレイヤー情報画面の対戦履歴で、その間のランク戦の勝敗と最長連勝を数えて裏付ける
4. **「世界で一番伸びた」とは書かない。** 開始時点で圏外だった人(9/28は58人)の伸び幅は分からない
5. 投稿直前に順位・レーティング・勝敗を取り直す(9/28は案を出してから投稿までの5分で53位→43位)

### 3. 文面を書く

型は`Xポスト案.md`の案1(今日の世界1位)・案7(上位の大接戦)が下敷きになる。
本文は日本語、ハッシュタグは`#クラロワ`と`#ClashRoyale`の両方。

```
ランク戦 世界ランキング{見出し=選んだ切り口を一言で}

世界1位 {名前} {レーティング}
世界2位 {名前} {レーティング} {←差分の注記}
世界3位 {名前} {レーティング}
(数字はレーティング)

{切り口を補足する一文}

非公式ファンサイト → https://princess-tower.duckdns.org/ranking/players?from=x
#クラロワ #ClashRoyale
```

投稿前に必ず確認すること:

- **世界か国別かを見出しと順位に書く。** 数字が何か(レーティング)と、時刻を書くなら基準
  (日本時間)も。「1位」「346位→43位」だけだと、読み手には世界か国別か分からない
  (2026-09-28にユーザーが指摘)

- **クラン名は原則書かない。** クラロワには`discord.gg/hog`のようなURL形式のクラン名が
  珍しくなく、Xが自動でリンク化して他人の招待リンクを自分の投稿に貼る形になる
  (2026-09-22に実際に起きた)。どうしても入れるなら`collect.py`が返す`clan`に
  ドメイン形式の文字列が無いか目視する
- **プレイヤー名にも同じ確認をする。** 名前がURL形式のこともある
- **`&lang=`は付けない。** 表示言語がCookieに保存される仕様のため、付けると踏んだ
  外国人ユーザーが以後ずっとその言語に固定される。詳細は`Xポスト案.md`の共通ルール
- **280字に収める。** 全角1文字=2、URL一律23、絵文字1つ=2。プレイヤー名に絵文字が
  入りがちなので見た目より早く上限が来る
- **数字は`collect.py`の出力をそのまま使う。** 差やポイント幅を手計算しない

### 4. 投稿する

`x-post`スキルの「投稿手順(ブラウザ操作)」に従う。要点だけ再掲:

- `https://x.com/compose/post`に直接遷移する
- テキストエリアは**毎回スクリーンショットで座標を確認してから**クリックする(ウィンドウ幅で位置が変わる)
- 短い1語を入れてフォーカスが入ったことを確認してから本文を流し込む
  (フォーカスが無いと文字がXのキーボードショートカットとして誤爆する)
- **Postボタンは1回目が効かないことが多い**。押したらスクリーンショットで確認し、
  送信されていなければもう一度押す

### 5. 記録する

- `Xポスト案.md`の該当案(案1または案7)に`〔実施済み〕`を付け、`X運用記録.md`の単独ポストの表に
  日時・使った切り口・実データ・ハマりどころを追記する
- `進捗ログ.md`には短いフェーズ項目として残し、詳細は`X運用記録.md`を参照させる
- 効果測定は後日`access-check`スキルで`?from=x`の件数と**ビーコンの実表示回数**を見る

## 履歴ファイルについて

`history/players.tsv`はタブ区切りで`日時 / 順位 / タグ / 名前 / レーティング`。
1回の実行で上位N人分の行が追記される。テキストなので直接読めるし、おかしな行は
消してよい(`collect.py`は空行と`#`始まりを無視する)。

**投稿しなかった実行分も記録に残る点に注意。** 連続首位日数は暦日で数えるので
1日に何度実行しても影響しないが、「前回との差分」は直前の実行が基準になる。
下見のつもりなら`--no-record`を付ける習慣にしておくと差分が素直になる。

サイトが応答しない・HTMLの構造が変わった場合、`collect.py`は空の結果でエラー終了する。
その場合は`https://princess-tower.duckdns.org/ranking/players`を直接見て、
表の構造が変わっていないか(`class="rank"`・`href="/player/..."`・`class="num"`)を確認する。

# 公式投稿への早い返信(princess-tower)

2026-09-27の反響分析(`X運用記録.md`の「反響の分析」)で、次のことが分かっている。

- 単独ポストはフォロワーが0人なので、ほとんど誰にも届かない(2〜60回)。
- 宣伝リプライは、自分の返信そのものが数十回しか見られない。
- **反応が付いたのは、リンクなしで話題に乗った会話だけ**だった。

公式の投稿は数千〜数万回見られていて、**早く付いた返信ほど上のほうに表示される**。そこに「このサイトにしか言えないデータ」を一言添え、プロフィールと固定ポストからサイトに来てもらう。
**サイトへの流入ではなく、いいね・返信・フォロワーを増やすのが目的**(2026-09-27にユーザーが採用)。

## ルール

- **リンクを入れない**。「サイトを作っています」のような自己紹介もしない。サイトへの導線はプロフィールと固定ポストに任せる。
- **ハッシュタグも付けない**(返信には不要なうえ、宣伝っぽく見えるため)。
- **公式の投稿の中身に直接つながるデータ**だけを書く。つながるデータが無いときは返信しない(無理に絡まない)。
- 返信は公式の投稿と同じ言語で書く(`@ClashRoyaleJP`なら日本語、`@ClashRoyale`なら英語)。
- **1日2件まで**。
- 投稿から時間が経つほど返信欄の下に沈むので、**投稿から1時間以内**を目安にする。数時間経っているものは見送る。
- 公式の告知を否定・揶揄しない。バグ報告に便乗して文句を言う形にもしない。

## 手順

### 1. 新着の投稿を探す

`claude-in-chrome`で公式のプロフィールを開き、新しい順に見る(操作の注意は`X運用記録.md`の「投稿の操作(ブラウザ)」)。

```
https://x.com/ClashRoyaleJP
https://x.com/ClashRoyale
```

返信しやすい投稿と、書けるデータの例:

| 公式の投稿 | 添えるデータ |
|---|---|
| バランス調整(強化・弱体化) | 対象カードの、世界トップ1000人の使用率(カード詳細画面)。「調整前の今、世界トップ1000人の◯%が使っています」 |
| 新カード・進化の発表 | 同じ役割のカードの今の使用率、同じレアリティの枚数(カード一覧画面) |
| シーズンの開始・終了 | ランク戦の世界1位・国別1位・トップ1000人の国籍(`ranking-live`・`top1000-countries`スキルの集計) |
| クラン対戦・イベント | クランランキングの上位の国(`Xポスト案.md`の案22の集計) |

カードの使用率は、カード詳細画面から取れる(カードIDはカード一覧画面のリンクで分かる)。

```bash
curl -s "https://princess-tower.duckdns.org/card/<カードID>?lang=ja" | sed 's/<[^>]*>/ /g' | tr -s ' \n' | grep -oE '使用率 [0-9.]+%'
```

### 2. 返信文を作る

- 1〜2文で書く。データを先に出す。
- **公式の投稿を読んだプレイヤーの「気付き」になるデータを選ぶ**(2026-09-30にユーザーの経験則として指示。気付きのある方がリアクションが多い。絶対ではない)。公式の話題を自分のプレイに引き寄せて考えられる事実がよい(例: 弱体化されるカードを、今ランク戦の上位で何%が使っているか。対戦でどれくらい見かけるかの目安になる)。「これ誰のメリット？」と自問し、読み手の役に立たない豆知識は外す。気付きになるデータが無ければ、上の「ルール」のとおり返信しない。
- 集計の出どころは短く書く(「世界トップ1000人の直近のランク戦では」など)。
- 文字数はXのカウンタの残り表示で確かめる。

例:
```
調整前の今、ランク戦の世界トップ1000人のうち9.9%がホグライダーを入れています。弱体化のあとどこまで減るか気になりますね
```

### 3. ユーザーの確認を取る(必須)

公式の投稿の要約・投稿からの経過時間・返信文を示して、`AskUserQuestion`で確かめる。**確認なしに送信しない。**

### 4. 送信する

`x-reply-promo`スキルの「5. 送信する」と同じ手順で送る(インラインの返信欄を使う。フォーカスを確かめてから入力する)。

### 5. 記録する

- `X運用記録.md`の「公式投稿への返信」の表に1行足す。
- **翌日以降に、自分の返信の表示回数・いいね・返信と、フォロワー数を追記する**。この方法が効いているかは、これらの数字で判断する。
